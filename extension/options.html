ytmine

This extension shows ytmine's captions on youtube.com. The ytmine program must be running on this computer.

Connection

Checking…
  1. Start ytmine on this computer. Its page opens in your browser.
  2. Keep that page open for a moment. The extension connects by itself, and this box turns green.

ytmine already running? Press the button to open its page.

Manual setup

You only need this if connecting by itself does not work.

The address of the ytmine page. It must be on this computer.

On the ytmine page, open Browser extension (under the card list) and press Copy pairing token. You can also run ytmine --show-token in a terminal.

Captions

Hotkeys

Click a box and press the key you want. They do nothing while you are typing in a text box. YouTube already uses Space, K, J, L, F, M, C and the arrow keys, so those are best avoided. Press Backspace in a box to restore its default.
