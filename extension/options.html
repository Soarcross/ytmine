ytmine

This extension shows ytmine's captions on youtube.com. The ytmine program must be running on this computer.

Connection

Leave this as it is unless you started ytmine on another port. It must be on this computer.

ytmine prints the token when it starts. To see it again, run ytmine --show-token. You only need to paste it once.

Captions

Hotkeys

Click a box and press the key you want. They do nothing while you are typing in a text box. YouTube already uses Space, K, J, L, F, M, C and the arrow keys, so those are best avoided. Press Backspace in a box to restore its default.
